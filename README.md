# task30-Statistical-Data-Visualization-using-Seaborn
Project Overview

This project demonstrates statistical data visualization using Python, Pandas, Seaborn, and Matplotlib. The Iris dataset is used to explore flower measurements and visualize patterns in the data.

Objective

To learn how Seaborn simplifies statistical data visualization and how to interpret different types of statistical plots.

Tools and Technologies
Python
Pandas
Seaborn
Matplotlib
Jupyter Notebook
Scikit-learn
Dataset

The Iris dataset contains 150 flower samples from three species:

Setosa
Versicolor
Virginica

Measurements include sepal length, sepal width, petal length, and petal width.

Visualizations
1. Count Plot

Displays the number of flowers in each species.

2. Histogram

Shows the distribution of petal lengths.

3. Box Plot

Compares petal-length distributions, medians, and potential outliers across species.

4. Scatter Plot

Shows the relationship between petal length and petal width, with different colors for each species.

5. Correlation Heatmap

Visualizes the correlation between numerical flower measurements.

Seaborn vs Matplotlib

Seaborn provides convenient statistical plotting functions and attractive default styles. Matplotlib provides detailed control over graph elements and layouts. Both libraries can be used together.

How to Run the Project
Install Python and Jupyter Notebook.
Open Jupyter Notebook.
Install the required packages:
bash
pip install pandas seaborn matplotlib scikit-learn

Load the Iris dataset using Scikit-learn.
Run the notebook cells in order.
Observe and interpret all five visualizations.
Key Findings
Each species has 50 samples.
Setosa generally has shorter petals than the other species.
Petal length and petal width have a strong positive relationship.
Box plots help compare distributions across species.
Heatmaps help identify correlations between numerical variables.
Conclusion

This project demonstrates how Seaborn can simplify statistical data visualization. The five plots help identify distributions, compare categories, examine relationships, and understand correlations in a dataset.
